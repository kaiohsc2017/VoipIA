Como registrar o comando "asteriskia-agent" para rodar de qualquer diretório
=============================================================================

O agente-google.py é chamado através de um wrapper simples em /usr/local/bin,
diretório que já está no PATH padrão de qualquer shell Linux.

1. Criar o wrapper (ajuste o caminho do "cd" para onde o agente-google.py
   estiver nesta máquina):

cat > /usr/local/bin/asteriskia-agent <<'EOF'
#!/bin/bash
cd /opt/AsteriskIA/tools
python3 agente-google.py "$@"
EOF

2. Dar permissão de execução:

chmod +x /usr/local/bin/asteriskia-agent

3. Usar de qualquer diretório, em qualquer sessão SSH:

asteriskia-agent

Por que funciona: /usr/local/bin já está no $PATH por padrão. O wrapper faz
"cd" para dentro da pasta tools/ antes de chamar o Python porque o script
espera ser executado a partir dali (ou usa a variável ASTERISKIA_DIR para
achar o .env do projeto).
